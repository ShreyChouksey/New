Perspective

The Observable Universe

Contains roughly 1080 atoms. This archive contains 10{{ archive_stats.total_images_digits - 1 }} images — a number so large that the number of atoms in the universe is essentially zero by comparison.

Every Image Ever

Every photograph ever taken, every painting ever painted, every frame of every film — they all exist somewhere in this archive, at their {{ archive_stats.resolution }} quantized version. So does your face, and every possible variation of it.

Mostly Noise

The overwhelming majority of images in the archive are indistinguishable from random noise. Finding a meaningful image by random browsing is essentially impossible — which is exactly what makes the search function so powerful.

Nothing Is Stored

No images are stored anywhere. The entire archive is a mathematical function — a reversible mapping between addresses and pixel data. The archive takes zero storage space yet contains everything.

REST API

GET /api/v1/browse/<address>

Retrieve an image by address. Returns JSON with base64 image and metadata.

POST /api/v1/search

Upload an image (multipart form) to find its archive address.

GET /api/v1/random?count=N

Generate N random images with addresses and base64 data.

GET /api/v1/stats

Archive configuration and statistics as JSON.

GET /api/v1/gallery/<room>/<wall>/<shelf>

Get image addresses for a specific gallery shelf.

GET /api/v1/explore/<address>

Get neighboring addresses around a center address.

GET /image/<address>.png?scale=N

Raw PNG image served directly. Immutable cache headers. Use in <img> tags.
